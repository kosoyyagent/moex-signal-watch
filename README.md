# moex-signal-watch

Монитор торговых сигналов Московской биржи (режим TQBR, акции) с
уведомлениями в **Telegram** и/или **MAX**. Одна зависимость — публичный
API MOEX ISS, ключи не нужны.

## Сигналы

| Сигнал | Источник в ISS |
|---|---|
| Свеча ±N% по тикеру | `LASTCHANGEPRCNT` к предыдущему закрытию |
| Приостановка торгов по акции | переход `TRADINGSTATUS` из `T` в другой код |
| Изменение биржевых планок | `LIMITUP`/`LIMITDOWN`, когда ISS их отдаёт |
| Изменение плечей | данные брокера — точка расширения, см. ниже |

Плечи (маржинальные ставки) по ISS не транслируются — это данные брокера.
Подключение API брокера (Alor, T-Invest, Finam) — одна функция в коде.

## Запуск

```bash
python signal_watch.py --demo          # на реальном снимке ISS из репо
python signal_watch.py --demo --shock  # + тестовые сигналы, проверка алертов
python signal_watch.py                 # боевой опрос каждые POLL_SECONDS
```

```bash
pip install -r requirements.txt   # только если нужен .env-файл; ядро — чистый stdlib
```

## Настройка

- `watchlist.txt` — тикеры по одному в строке
- `THRESHOLD_PCT` — порог свечи в % (по умолчанию 2.0)
- `POLL_SECONDS` — интервал опроса (60)
- `TG_TOKEN`, `TG_CHAT` — Telegram-бот и чат
- `MAX_TOKEN`, `MAX_CHAT` — MAX-бот и чат

Без токенов алерты печатаются в консоль (`[dry]`). `state.json` защищает от
повторных алертов по тому же сигналу.

## Демо-вывод

```
[dry] 📈 GAZR Газпром: свеча +3.40% — цена 182.5
[dry] 🚨 SBER Сбербанк: торги приостановлены (было: торгуется)
```

`demo_snapshot.json` — реальный снимок ответа ISS по 9 голубым фишкам,
снятый с биржи. `--shock` добавляет две синтетические строки, чтобы
проверить форматирование алертов без ожидания реального события.
